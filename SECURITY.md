# Security

This is a cooperative demonstration for a trusted local user. It cannot constrain unrelated processes, reserve physical memory, enforce GPU limits or sandbox model output.

Do not use it as a production authorization service. Do not expose a future execution interface over a network without a separate design and security review.

Please avoid including confidential information in public issues. For a sensitive report, use GitHub's private vulnerability reporting if enabled; otherwise contact the maintainer through the contact route on the maintainer's public GitHub profile. Do not publish exploit details containing real credentials or private files.
